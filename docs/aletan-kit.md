# Алетан → Yandex KIT

Источники:

- Каталог: https://aletan.ru/upload/aletan_catalog_export.csv
- Закупочный прайс: https://docs.360.yandex.ru/view/d/_xpJcObcgUxWnp71fA8UZyPegnqahzm72s0qoIz-cKg6VUZsT1dCXzlhdw

Правила:

- Работать только с существующими активными товарами KIT, у которых бренд строго **Алетан**.
- Новые товары не создавать.
- Сопоставление: `vendorCode` из каталога ↔ артикул в названии/SKU/характеристиках KIT.
- Закупочную цену брать из всех товарных листов XLSX:
  - `Цена ФАБРИКИ`;
  - `Опт (руб.)`.
- `Реком.цена`, `Розница`, `РРЦ` и аналогичные колонки запрещено использовать как закупочную.
- Для цветовых вариантов с пустой ячейкой цены разрешено наследование закупочной цены внутри одной товарной группы.
- Закупочную цену в KIT не записывать.
- Цена для покупателя = закупочная цена × **1,30**.
- Цена до скидки = закупочная цена × **1,60**.
- Дробные результаты округлять **вверх до целого рубля**, как фактически хранит цены KIT.
- Обновлять только цены; названия, описания, изображения, категории и остатки не менять.
- Если один артикул имеет разные закупочные цены в прайсе — его автоматически пропускать.
- Если артикул неоднозначно сопоставился с несколькими карточками KIT — его автоматически пропускать.
- Автоматическая проверка запускается по вторникам в 12:35 UTC. Live-обновление выполняется только если с последнего успешного live-запуска прошло не менее **14 дней**.
- Изменения кода/настроек через push всегда запускают только `dry-run`, без записи цен в KIT.

Последний подтверждённый live-запуск: 22.09.2026.
После него контрольный dry-run подтвердил: 486 из 486 обновлённых карточек совпадают с расчётными ценами, 0 расхождений.
