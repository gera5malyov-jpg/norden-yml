# YourRoom → Яндекс KIT

Источник: https://yourroom.ru/  
Регион источника: Санкт-Петербург.

Правила синхронизации:

- поставщик во внутреннем отчёте: `ВашаКомната`; в характеристики KIT поле «Поставщик» не добавляется;
- каждая отдельная товарная страница/модификация создаётся отдельной карточкой;
- SKU после создания карточки: `YOU-<код KIT>`;
- «Цена для покупателя» = актуальная цена со скидкой;
- «Цена до скидки» = зачёркнутая цена; если её нет, используется текущая;
- склад `СПБ`: 100 шт.;
- если товар исчезает из полного товарного sitemap, остаток становится 0;
- из описания удаляются упоминания ВашаКомната / ВашаКомната.РФ / yourroom.ru;
- карточка без пригодной фотографии не создаётся;
- для фотографий сначала используется чистый оригинал/альтернативный файл без водяного знака; если его нет, скрипт пытается программно убрать водяной знак; изображение с оставшимся водяным знаком отбрасывается;
- автоматическое обновление — раз в 14 дней. GitHub Actions проверяет задачу раз в неделю, а интервал контролирует state.json.

Основной скрипт: `sync_yourroom_kit.py`  
Workflow: `.github/workflows/yourroom-kit-sync.yml`.
