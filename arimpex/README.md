# А.Р. ИМПЭКС - выгрузка для YML Pro

Источник: https://arimpex.ru/sitemap/sitemap_products.xml

Скрипт `arimpex/parser.py` обходит все модели из официального sitemap, извлекает перечисленные на сайте модификации из `window.__INITIAL_STATE__.detail.product.offers` и загружает каждую модификацию отдельно. Переносятся актуальная цена, старые цены (когда есть), характеристики, конфигурация материалов, фотографии и доступный остаток.

**Постоянная ссылка на YML после успешного первого запуска:**

https://raw.githubusercontent.com/gera5malyov-jpg/norden-yml/main/arimpex/arimpex.yml

Расписание: GitHub Actions `.github/workflows/arimpex-weekly.yml`, еженедельно по воскресеньям в 04:24 UTC (07:24 Москвы). Ручной запуск через `workflow_dispatch`.

Сопоставление YML Pro: идентификатор предложения `arimpex-<ID модификации>`. Каждый вариант имеет свой уникальный `vendorCode` формата `ARIMPEX-<ID>`, а исходный артикул модели хранится в `model` и параметре «Артикул производителя». В атрибуте `group_id` записана модель `arimpex-<ID модели>`. При настройке группировки модификаций в Webasyst необходимо проверить поддержку group_id используемой версией YML Pro.

`count` передаётся из фактического доступного остатка. Статус «Под заказ» не приравнивается к физическому наличию, поэтому `count=0`, но `available=true` (заказ допустим). Для неизвестных или недоступных статусов `available=false`.

Изображения преобразуются из URL imgproxy в постоянные оригинальные ссылки, когда такое преобразование возможно. В GitHub не скачиваются фотографии, используются ссылки. Скрипт не использует KIT и API Webasyst, и не меняет данные магазина. При любой ошибке получения модификаций или подозрительном сокращении каталога старый YML не перезаписывается.
