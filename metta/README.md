# METTA - все товары / все цвета -> YML Pro

Источник: https://www.metta.ru/spb/ (без рекламного roistat_visit); официальный sitemap-products.xml и открытые категории Санкт-Петербурга.

**Каждый `?offer=<ID>` - отдельная карточка**, включая разные цвета каркаса, сетки, обивочных материалов и исполнения. Стабильный `offer id=metta-<ID>`, свой артикул (код комплектации, если есть), цена, доступность и фотографии именно выбранного варианта. `group_id` общий для модификаций одной модели, не объединяет карточки.

Описания собираются из технических характеристик, а не из рекламного текста производителя. Телефоны, адреса, ссылки на поставщика, призывы к покупке, доставка и акции не включаются. Изображения по ссылкам оригинала, преимущественно официальные 3D-рендеры без дополнительного уменьшения.

Постоянная ссылка для YML Pro после успешной первой генерации:

https://raw.githubusercontent.com/gera5malyov-jpg/norden-yml/main/metta/catalog.yml

GitHub Actions: каждое воскресенье в 09:27 по Москве (06:27 UTC), ручной запуск и запуск при изменениях кода. При неполном обходе или исчезновении значительной части карточек предыдущий файл сохраняется. KIT и Webasyst API напрямую не изменяются.

Важно: сайт выдает товары в городских и общих адресах. Сопоставление делается по исходному артикулу/offer ID; публикация цены и наличия берется из конкретной страницы модификации. Если для пользователя нужны строго региональные цены Петербурга, потребуется отдельная проверка региональных данных, поскольку общие ссылки отличаются от /spb/ страниц.
