# Avalon - подстолья и столы для кафе

Источники:
- https://www.avalonmebel.ru/catalog/podstole-dlya-stola/
- https://www.avalonmebel.ru/catalog/stoly-dlya-kafe/

Только эти две категории. Парсер обходит страницы каждого каталога Bitrix через PAGEN_1, а не полный сайт и не его неполный sitemap. На 17.10.2026 подстолья: 346 позиций, 29 страниц; столы для кафе: 179 позиций, 15 страниц. Каждая категория проверяется отдельно; при ошибке старый YML не перезаписывается.

## Постоянная ссылка для YML Pro

https://raw.githubusercontent.com/gera5malyov-jpg/norden-yml/main/avalon-podstolya/catalog.yml

Каждая карточка получает постоянный YML offer id из URL, артикул vendorCode, название, цену, доступность, реальные фотографии из исходных /upload/iblock, характеристики (размер, вес, материал и другие опубликованные), описание. Старые ID подстолий не меняются (`avalon-...`), новые столы получают отдельный префикс `avalon-table-...`, чтобы исключить пересечения. Категория 1 - «Подстолья для столов», категория 2 - «Столы для кафе». Контактные данные, телефоны, адреса, предложение оплаты/доставки, текст о самом поставщике и реклама исключаются. В YML других категорий нет.

Расписание: один раз в неделю, понедельник 05:17 UTC (08:17 МСК). Ручной запуск в Actions. Сайт и KIT напрямую не изменяются; YML Pro в Webasyst необходимо настроить на этот URL.

Все карточки должны успешно обработаться, иначе генерация отклоняется. Если цена отсутствует, offer получает 0, available=false и параметр «Цена по запросу». Изображения хранятся как публичные ссылки на оригинальные фотографии, а не как файлы в GitHub. Чертеж с размерами берётся из отдельного блока характеристик `.sku__chars .magnific-gallery__item1` и всегда помещается **последним** `<picture>` в карточке YML; при ограничении в 35 изображений для схемы резервируется место. Если схемы нет на странице источника, не подставляем чужое изображение.
