# Treez → Яндекс KIT

Автоматическая загрузка каталога Treez в Яндекс KIT.

Правила:
- каждая модификация/артикул источника обрабатывается как отдельная позиция;
- бренд: `TREEZ`;
- поставщик: `treez`;
- SKU после создания: `TREEZ-<код KIT>`;
- цена для покупателя: цена Treez × 0.97;
- цена до скидки: исходная цена Treez;
- склады `МСК` и `СПБ привозной`: по 100;
- если позиция исчезла из источника, её остатки на этих двух складах становятся 0;
- изображения переносятся при создании;
- для карточек с прямым видеофайлом выполняется попытка загрузить видео в KIT;
- live-обновление выполняется не чаще одного раза в 14 дней;
- после запуска отправляется отчёт на `shop@office-mag.com`.

Источник структуры каталога:
`https://s3.q-parser.ru/automata/612af8f7ec414c/treez.ru.xml`

Секреты GitHub Actions:
- `YANDEX_KIT_TOKEN`
- `GMAIL_SMTP_USER`
- `GMAIL_APP_PASSWORD`
