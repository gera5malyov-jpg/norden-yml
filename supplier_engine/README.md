# Supplier Import Engine

Единый движок импорта поставщиков для схемы **Источник → GitHub Actions → Webasyst**.

Поддерживаемые источники в целевой архитектуре: XLSX, CSV, YML/XML, API, PDF, URL и файлы из почты/хранилища.

Ключевые правила:
- Webasyst — мастер-база.
- Сопоставление выполняется по стабильному артикулу поставщика и итоговому SKU с префиксом.
- Нельзя создавать дубль при повторном импорте.
- Перед записью выполняется dry-run.
- Резкое падение числа строк блокирует обнуление остатков.
- Аномальные цены и пустые SKU блокируют импорт.
- Изображения, характеристики, цены и остатки обновляются независимо по настройкам поставщика.
- PDF считается ненадёжным источником и требует усиленной валидации.
- Старые workflow не отключаются до успешной параллельной проверки нового адаптера.
