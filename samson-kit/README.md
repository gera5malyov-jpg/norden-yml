# Samsonopt → Yandex KIT

Изолированный импорт каталога Samsonopt в Yandex KIT. Все варианты принадлежат интеграции по префиксу `SAMS-`.

## Правила

- Samson `531863` → KIT `SAMS-531863`.
- Целевая точка остатков: единственный активный склад KIT с точным названием `СПБ`.
- Остаток = сумма всех остатков Samson. Подтверждённый активный ноль → `100`; снят/удалён → `0`.
- Закупка `<= 3000` → цена продажи `×1.40`; выше → `×1.26`; цена до скидки `×1.80`; минимальная `×1.20` рассчитывается, но не отправляется, пока поле KIT не подтверждено.
- Для существующих `SAMS-*` обновляются только цена и склад `СПБ`.
- Новые товары создаются с категориями, названием, описанием, брендом, характеристиками, штрихкодами и изображениями, если эти данные есть в Samson и поддерживаются KIT.
- Товар, отсутствующий в Samson, обнуляется только после полностью успешного прохода каталога.
- Webasyst-плагин `yandexkitsync` v0.9.6 должен быть установлен до live-импорта: он полностью игнорирует `SAMS-*`.

## Secrets

В GitHub → Settings → Secrets and variables → Actions добавить:

- `SAMSON_API_KEY`
- `YANDEX_KIT_TOKEN`

Никакие значения секретов в репозиторий не записываются.

## Первый запуск

Сначала используйте ручной workflow с `dry_run=true`, `max_items=20`. После проверки отчёта можно выполнить ограниченный live-тест. Недельный cron включается только после успешного smoke-test.
