# Парсер каталога stol-transformer.ru/showcase/

Парсер защищённого каталога LEVMAR для репозитория `norden-yml`.

## Главный принцип: одна модификация = одна товарная позиция

Пример:

`https://stol-transformer.ru/showcase/stol-transformer-zhurnalnyj-levmar-accord-r-d95s53-belyj-mramor-ozon-AR9553`

Парсер трактует эту страницу как отдельную позицию:

- базовая модель: LEVMAR Accord R D95S53;
- цвет: Белый мрамор;
- артикул: AR9553;
- изображения: только изображения этой конкретной модификации;
- розничная цена: отдельное поле `retail_price`;
- оптовая/закупочная цена: отдельное поле `purchase_price`;
- характеристики: все товарные характеристики со страницы.

Другой цвет этой же модели должен быть отдельной строкой/карточкой со своим артикулом, своими изображениями и ценами.

## Что собирается для каждой позиции

- `sku` — артикул конкретной модификации;
- `name` — полное название;
- `model` — модель/серия;
- `color` — цвет;
- `support_color` — цвет опор/ножек, если есть;
- `retail_price` — розничная цена;
- `purchase_price` — оптовая/закупочная цена;
- `old_price` — старая/зачёркнутая цена, если есть;
- наличие/остаток;
- бренд/производитель;
- категория;
- описание;
- все изображения конкретной позиции;
- все характеристики;
- доступные варианты/опции;
- исходная ссылка на карточку.

## Жёсткое правило по закупочной цене

`purchase_price` НИКОГДА не добавляется в `characteristics`.

При последующей интеграции:
- в KIT/Webasyst/Ozon и другие системы `purchase_price` можно передавать только в штатное поле «Закупочная цена» / себестоимость, если такое поле существует;
- если штатного поля закупочной цены нет — значение не загружается;
- создавать характеристику «Закупочная цена», «Оптовая цена» и аналогичные запрещено.

## Артикул

Приоритет:
1. явное поле «Артикул / SKU / Код товара» на странице;
2. структурированные данные карточки;
3. окончание URL.

Например URL, заканчивающийся на `-AR9553`, даёт резервный артикул `AR9553`.

## Изображения

Парсер не забирает все изображения страницы подряд. Он ищет изображения только внутри товарной галереи/карточки плюс `og:image`. Это снижает риск подмешивания баннеров, логотипов и фотографий соседних товаров.

## Результаты

- `stol-transformer/output/products.json` — полный структурированный каталог;
- `stol-transformer/output/products.csv` — таблица;
- `stol-transformer/output/report.json` — отчёт запуска.

## Авторизация

Пароль специально не хранится в коде и истории GitHub.

Нужно создать два GitHub Actions Secrets:
- `STOL_TRANSFORMER_LOGIN`
- `STOL_TRANSFORMER_PASSWORD`

Парсер поддерживает HTTP Basic Auth и обычную HTML-форму авторизации с cookies.

## Запуск

GitHub → Actions → **STOL-TRANSFORMER — Parse protected catalog** → Run workflow.

После успешного запуска результат коммитится обратно в репозиторий и сохраняется как artifact.
