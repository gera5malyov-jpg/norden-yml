# Парсер каталога stol-transformer.ru/showcase/

Парсер защищённого каталога LEVMAR для репозитория `norden-yml`.

## Что собирается

- название товара;
- артикул / SKU / код товара, если он есть на странице;
- текущая и старая цена;
- наличие / остаток, если он есть;
- бренд / производитель;
- категория;
- описание;
- все найденные изображения;
- характеристики;
- варианты товара (цвета, опоры и другие опции);
- ссылка на карточку.

Результаты сохраняются в:
- `stol-transformer/output/products.json` — полный структурированный каталог;
- `stol-transformer/output/products.csv` — таблица для проверки/импорта;
- `stol-transformer/output/report.json` — отчёт запуска.

## Авторизация

Пароль специально не хранится в коде и истории GitHub.

Нужно создать два GitHub Actions Secrets:
- `STOL_TRANSFORMER_LOGIN`
- `STOL_TRANSFORMER_PASSWORD`

Парсер автоматически поддерживает:
1. HTTP Basic Auth;
2. обычную HTML-форму авторизации с cookies.

## Запуск

GitHub → Actions → **STOL-TRANSFORMER — Parse protected catalog** → Run workflow.

После успешного запуска результат автоматически коммитится обратно в репозиторий и дополнительно сохраняется как artifact.

По умолчанию обход ограничен 2500 страницами и задержкой 0.15 сек между запросами, чтобы не создавать лишнюю нагрузку на сайт.
