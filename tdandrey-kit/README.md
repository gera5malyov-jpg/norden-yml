# ТД Андрей → Yandex KIT + Webasyst

Источник хранится только в GitHub Actions secret `TDANDREY_EXPORT_URL`.

Правила:
- KIT SKU: `AND-` + `sku` поставщика, например `AND-070168`.
- KIT: цена для покупателя = закупка × 1.26.
- KIT: цена до скидки = закупка × 1.80.
- KIT: минимальную цену не менять.
- KIT: `stock.msk.value` → склад `МСК`; `stock.spb.value` → склад `СПБ`.
- KIT: новые товары создаются независимо от текущего остатка, но только при положительной закупочной цене.
- Webasyst: только существующие товары типа `ТД Андрей автовыгрузка`; новые карточки не создаются.
- Webasyst: закупочная цена = `valueOpt`; цена продажи = закупка × 1.25; цена до скидки = закупка × 1.80.
- Для закупки берётся максимальная положительная `valueOpt` среди МСК/СПб с фактическим остатком. Если оба остатка 0 — максимальная положительная `valueOpt` МСК/СПб.
- Если ранее сопоставленный товар исчез из выгрузки, его остатки обнуляются, цены сохраняются.

Порядок первичной загрузки:
1. Сверить существующие товары Webasyst типа `ТД Андрей автовыгрузка` с API поставщика.
2. Сначала создать/сопоставить эти товары в KIT.
3. Затем пакетами загрузить весь каталог ТД Андрей в KIT.
4. После первичной загрузки ежедневно обновлять KIT и цены существующих товаров Webasyst.
