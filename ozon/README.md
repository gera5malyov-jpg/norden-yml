# Ozon: автоматическое заполнение ТН ВЭД

Этот workflow проверяет товары Ozon Seller через API и изменяет только характеристику ТН ВЭД.

## Безопасное правило

Автоматически записывается только подтверждённое значение:

1. явное значение для конкретного offer_id из `tnved_overrides.json`;
2. единый ТН ВЭД у другого варианта того же `model_id` Ozon в той же категории и типе товара;
3. явное проверенное значение для пары `description_category_id:type_id` из `tnved_overrides.json`.

Если источник неоднозначный, товар не меняется и попадает в отчёт GitHub Actions. Уже заполненный ТН ВЭД не изменяется.

## GitHub Secrets

В Settings → Secrets and variables → Actions → Repository secrets должны быть:

- `OZON_CLIENT_ID`
- `OZON_API_KEY`

Значения нельзя хранить в публичном коде.

## Запуск

Workflow: **Ozon TN VED sync**.

По расписанию он запускается один раз в сутки в режиме записи. Ручной запуск по умолчанию работает как dry run; для реальной записи при ручном запуске выберите `dry_run=false`.

Скрипт также читает дневной лимит обновлений Ozon через `/v4/product/info/limit` и не пытается превысить оставшуюся квоту.
