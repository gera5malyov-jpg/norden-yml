# KIT backup → Google Sheets

Резервная копия каталога Яндекс KIT в Google Таблицу `KIT`.

## Источник данных

1. Основной: API Яндекс KIT через секрет `YANDEX_KIT_TOKEN`.
2. Резервный: YML-фид:
   `https://yastore-prod-persist.s3.yandex.net/feeds/yml/019a5a60-ce41-7872-aa9d-d7720c268dab.xml`

API используется в приоритете, потому что он отдаёт внутренние поля вариантов, статусы, характеристики, остатки, медиа и служебные идентификаторы. YML используется автоматически, если API недоступен.

## Google Таблица

Spreadsheet ID:
`1xZUeaWUr-6O3KK0MO-1U7IGBKXXfgcmZ-EJ-w-2wWug`

В таблице создаются/обновляются листы:
- Товары
- Характеристики (при большом объёме автоматически делится на несколько листов)
- Остатки
- Медиа
- Справочник характеристик
- Категории
- Склады
- Продукты API
- Сводка
- История

Для каждого варианта также сохраняются JSON-поля и фрагменты полного raw JSON, чтобы не терять поля, которые не вынесены в отдельные колонки.

## GitHub Actions

Workflow выполняется ежедневно и может запускаться вручную.

Каждый запуск также создаёт полный gzip JSON backup `kit_full_backup.json.gz` и публикует его как GitHub Actions artifact с хранением 90 дней.

## Авторизация Google Sheets

Нужен GitHub Actions secret:

`GOOGLE_SERVICE_ACCOUNT_JSON`

Значение — JSON ключ Google Service Account целиком либо его Base64-представление.

Таблицу KIT необходимо один раз предоставить на редактирование email-адресу `client_email` из этого JSON.

Если Google secret ещё не настроен, выгрузка из KIT всё равно выполняется и сохраняется как Actions artifact; синхронизация таблицы будет пропущена с предупреждением.
