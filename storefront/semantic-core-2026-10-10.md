- Проверены 808 видимых категорий Webasyst по базе (read-only), 65 крупнейших по числу активных товаров с остатком, реальные метатеги и существующие URL категорий.
- Названия фраз ниже - **гипотезы коммерческого спроса** на основе реального ассортимента и интента, а не подтвержденные частотности. Для количественного ранжирования требуется экспорт KIT `SEO → Ключевые слова` и статистика Яндекс Вебмастера `Поисковые запросы`.
- Не создавать «города»-дорвеи, не обещать мгновенную доставку/цены/наличие без подтверждения; не генерировать массовые SEO-тексты с повторами.
- Товары, цены, остатки и распределение категорий, особенно без основной категории, не менять.

## Технические результаты
- 823 категорий всего; 808 видимых; у всех 808 отсутствуют **индивидуально сохраненные** мета Title и Description, но на витрине действуют динамические SEO-шаблоны.
- 766 видимых категорий не имеют содержательного описания.
- На нескольких страницах категории генерировалось `руб..` в HTML meta description; сайт исправлен отдельной scoped-темой Stage 33.
- На главной странице описание говорило «200 000+ товаров» при ~115 тыс. активных товаров по последнему аудиту; описание исправлено без точной цифры.
- Проблема дублирующихся slug товаров в Sitemap существует отдельно и не должна решаться заменой SEO-текста.
- SEO-поля `seo_title`, `seo_description`, `seo_h1` в KIT существуют, но могут оставаться пустыми: KIT использует шаблоны Title/Description, а также автоматически создает SEO-коллекции при условиях платформы. Это не изменяет автоматически Webasyst.

## Информационно-коммерческие темы для полезных текстов категории
- Компьютерные кресла: механизм качания, поясничная поддержка, подлокотники, материалы, габариты, весовая нагрузка (только подтвержденные атрибуты конкретного товара).
- Кресла руководителя: регулировки посадки, материал обивки, габариты, основание, рекомендации по выбору высоты.
- Стулья для посетителей: вместимость приёмной, материал и уход, складываемость только если подтверждена.
- Столы: размеры рабочей поверхности, материал столешницы, размещение в офисе и дома, комплектация.
- Стулья обеденные: высота сиденья, материал каркаса, обивки, эргономика и уход.
- Шкафы: размеры, тип дверей, комплектация, безопасное размещение.
- Диваны: назначение помещения, размеры, тип обивки, инструкции по уходу.
- Зеркала: формат, монтаж, безопасность крепления, стиль.
- Медицинская мебель: нельзя писать «медицинское изделие» или «с РУ» без подтвержденной регистрации каждой модели.

## Архитектура SEO без дублирования
1. Главная: широкие интенты «мебель и предметы интерьера», «мебель для дома и офиса», регион Санкт-Петербург и доставка РФ.
2. Категория: один основной коммерческий кластер (например «кресла руководителя») + 2-3 естественных синонима в уникальном тексте; не создавать страницы по одному синониму.
3. Товар: модель/артикул + бренд + характеристики из подтвержденных данных; не подменять существующий технический slug без точной карты 301.
4. Страница производителя: существующий список 432 названий пока ведет в поиск; отдельные индексируемые страницы брендов полезны лишь после сверки реального ассортимента и отсутствия дублей.
5. Сортировки и фильтры: не создавать сотни автоматически индексируемых дублей; canonical/robots проверять индивидуально. Пагинация требует отдельного аудита.
6. Блоки FAQ добавлять только из реальных вопросов покупателей; не выдавать рекламные предположения за проверенные факты.
7. Не перекладывать SEO с Яндекс KIT на Webasyst автоматически: у платформ разные адреса и настройки. Экспорт KIT SEO → Ключевые слова использовать как источник данных для анализа, но **не** публиковать все автоколлекции на profikompany.ru без проверки.

## Дальнейшая работа на основе фактической частотности
1. Выгрузить из Яндекс KIT SEO → Ключевые слова Excel, а из Яндекс Вебмастера Поисковые запросы (за 3-6 месяцев) с кликами, показами, CTR и позицией.
2. Сопоставить фразы с существующими посадочными страницами и группами товаров.
3. Разделить: высокие показы с низким CTR -> Title/Description; запросы на 2-3 странице выдачи -> контент и внутренние ссылки; без посадочной страницы -> рассмотреть существующую категорию/полезную подборку.
4. После качественной проверки добавить 10-20 индивидуальных текстов категории на основании реального ассортимента и потребностей, не трогая товары без категории.
5. Повторить проверку индексации и поискового спроса через 2-4 недели; результат ранжирования не гарантируется.
