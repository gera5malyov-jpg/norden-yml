# Z3K - все товары строительного инструмента и оборудования

Каталог: https://z3k.ru/ . Сайт работает на HostCMS, полный sitemap https://z3k.ru/sitemap.xml содержит около 2745 ссылок (часть - категории). Парсер читает все адреса /shop/, товары отделяются по стабильному идентификатору кнопки `data-item-id`.

Каждый отдельный товар и модификация с отдельным ID становятся самостоятельным `<offer>` (id `z3k-<HostCMS ID>`), не объединяются по цвету. Характеристики и торговый артикул загружаются с товара; изображения по оригинальным публичным ссылкам. Контакты, реклама и сведения о поставщике исключаются из описания; производитель оборудования сохраняется как факт (Бренд).

Наличие: «В наличии» ставит available=true; «Ожидаем поступление» и неизвестное наличие - false. При отсутствии цены ноль, предложение недоступно. Категории создаются автоматически.

Постоянный URL для YML Pro, как только успешно создан catalog.yml:

https://raw.githubusercontent.com/gera5malyov-jpg/norden-yml/main/z3k/catalog.yml

Запуск в GitHub Actions каждое воскресенье 10:17 Москва (07:17 UTC), вручную и при изменении кода. При существенном падении числа позиций, дублях ID или сетевых ошибках старый YML сохраняется. KIT/Webasyst напрямую не изменяется.
