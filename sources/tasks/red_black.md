# Red Black

Источник: `sources/yml_sources.json -> red_black`.

Правила синхронизации:

- Все управляемые товары имеют артикул `RED-`.
- Для новых товаров SKU формируется как `RED-00-XXXXXXXX`, где артикул поставщика приводится к 8 цифрам.
- Существующие товары в Yandex KIT: контент не менять; обновлять только цену продажи и остатки.
- Новые товары в Yandex KIT: создавать с названием, описанием, категорией, параметрами и всеми изображениями из полной выгрузки.
- `<price>` — закупочная цена. В Yandex KIT её не записывать.
- `<price>` используется в Google-таблице (колонка «Цена закупки») и в `purchase_price` Webasyst.
- `<rrc_price>` — цена для покупателя. Её обновлять в Yandex KIT и как обычную цену продажи в Webasyst.
- `<stock>` — фактический остаток поставщика. В KIT одно и то же реальное количество ставить на склады `МСК` и `СПБ привозной`.
- В Webasyst реальный остаток писать только на склад `Red МСК`.
- Если товар исчез из полной выгрузки: цену не менять; остаток установить в 0 в обоих складах KIT и на `Red МСК` Webasyst.
- В Webasyst существующие карточки переводить/держать в типе товара `RED-Black1`; отсутствующие карточки создавать.
- Для новых карточек Webasyst каждое изображение помещать в краткое описание отдельным блоком:
  `[extimg]\nURL\n[/extimg]`.
- Ежедневный запуск выполняется через GitHub Actions.
- Перед записью применяется защита от пустой/неполной выгрузки и от массового создания дублей.
