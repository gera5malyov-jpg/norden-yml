# Внешние YML-источники

Этот раздел зарезервирован как отдельный реестр внешних YML/XML-источников для будущих автоматизаций.

Сейчас подключены:

- Red Black
- Riva
- Everprof

Сами ссылки хранятся в `yml_sources.json`.

Пока никакая обработка этих файлов не выполняется: источники только зафиксированы отдельно, чтобы позже добавлять задачи и правила обработки без смешивания с текущей логикой Norden.
