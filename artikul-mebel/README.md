# Artikul-Mebel YML parser

Автоматический парсер каталога https://artikul-mebel.ru/.

Проект размещён внутри репозитория `gera5malyov-jpg/norden-yml` в отдельной папке и не изменяет действующий парсер Norden.

## Что делает

- ищет карточки товаров через sitemap.xml;
- если sitemap недостаточен, обходит каталог и пагинацию;
- собирает название, артикул, категорию, розничную цену, цену от количества, минимальное количество, остаток, описание, изображения и технические характеристики;
- формирует стандартный YML-фид `catalog.yml`;
- обновляется через GitHub Actions еженедельно по воскресеньям в 07:41 по Москве;
- поддерживает ручной запуск через **Actions → Update Artikul-Mebel YML → Run workflow**;
- не перезаписывает нормальный фид, если сайт внезапно вернул слишком мало товаров.

## Постоянная ссылка

`https://raw.githubusercontent.com/gera5malyov-jpg/norden-yml/main/artikul-mebel/catalog.yml`

## Формат YML

В `offer` сохраняются:

- `url`;
- `price`;
- `currencyId=RUR`;
- `categoryId`;
- до 20 `picture`; исходные ссылки `/upload/iblock/` вместо Bitrix `/upload/resize_cache/` (позволяет избежать наложенных при ресайзе водяных знаков; водяные знаки внутри самого файла не удаляются);
- `name`;
- `vendor=Артикул-Мебель`;
- `vendorCode` — артикул производителя;
- `description`, без телефонов, email, адресов, рекламных обращений поставщика;
- технические характеристики как `<param>`;
- `Оптовая цена`;
- `Минимальное количество для оптовой цены`;
- `Остаток`, если он опубликован на сайте;
- `Цена по запросу=Да`, если розничная цена отсутствует или равна 0.

## Локальный запуск

```bash
cd artikul-mebel
pip install -r requirements.txt
python -m pytest -q
python parser.py
```

Настройки можно менять переменными окружения:

- `MIN_PRODUCTS` — минимальное безопасное число товаров, по умолчанию `100`;
- `WORKERS` — количество параллельных запросов, по умолчанию `4`;
- `OUTPUT` — имя выходного файла, по умолчанию `catalog.yml`;
- `REQUEST_TIMEOUT` — таймаут одного запроса, по умолчанию `45` секунд.

## Проверка полноты и сетевой резерв

Входной официальный sitemap содержал 441 ссылку на товарные карточки по состоянию на 16.10.2026. Скрипт дополнительно извлекает Bitrix-модификации `oID` из каждой карточки. Если пропала хотя бы одна заявленная модификация, обновление не публикуется. В случае отказа сайта в соединении GitHub Actions может использовать временный запуск через NetAngels VM по секрету `NETANGELS_API_KEY` и затем публикует тот же файл.

Сайт может наносить водяной знак непосредственно на исходный JPG; в этом случае замена ссылки на исходник не уберёт этот знак. Файл нельзя считать гарантированно свободным от встроенных водяных знаков без визуальной проверки оригинальных фотографий.
