# Dalli: аккаунты по складам

В интеграции используются два отдельных аккаунта Dalli.

| Аккаунт | Назначение | GitHub Secret | API endpoint |
|---|---|---|---|
| 1 — СПБ | Отправка со складов Санкт-Петербурга | `DALLI_TOKEN` | `https://spbapi.dalli-service.com/v1` |
| 2 — МСК | Отправка со складов Москвы | `DALLI_TOKEN_MSK` | `https://api.dalli-service.com/v1` |

## Выбор аккаунта

В GitHub Actions workflow **Dalli API — СПБ и МСК** используется параметр `account`:

- `spb` — первый аккаунт, склады СПБ;
- `msk` — второй аккаунт, склады МСК.

Секреты не должны храниться в файлах репозитория. Для второго аккаунта токен необходимо добавить в **Settings → Secrets and variables → Actions** под именем `DALLI_TOKEN_MSK`.


## Правила оформления заказов

- Телефон получателя передавать полностью. Для Ozon использовать `addressee.phone` и, если есть `addressee.pin`, добавлять его как `доб. PIN`.
- В поле `instruction` передавать только примечание, которое покупатель написал в заказе. Служебные комментарии туда не добавлять.
- Для каждой товарной позиции Dalli передавать `VATrate="0"` — «Без НДС».
- Не использовать `autosend=T` без отдельного указания: заказ должен оставаться в корзине до явной отправки.

- Подъём из Ozon добавлять в Dalli только если у `prr_option.price` есть отдельная сумма > 0: `lift` → `climb type="elevator"`, `stairs` → `climb type="stairs"`; этаж брать из `prr_option.floor`.
- Если `prr_option.code="delivery_default"` («Подъём на этаж включён в стоимость доставки») или сумма подъёма 0 — отдельный подъём в Dalli не добавлять.

- Для Яндекс Маркета телефон передавать полностью: `phone` + `phoneExtension`, если добавочный есть. Примечание — только комментарий покупателя. НДС товара — 0.
- Для Яндекс Маркета подъём добавлять только при отдельной `liftPrice > 0`; `ELEVATOR/CARGO_ELEVATOR` → elevator, `MANUAL` → stairs. Бесплатный/включённый подъём отдельно не добавлять.
- Для оплаченного ПРР использовать КГТ: сначала service 30; если для адреса нет интервалов — service 32 «Доставка КГТ Регион».

- Для Ozon и Яндекс Маркета подъём в Dalli добавлять только при наличии отдельной положительной суммы подъёма в данных маркетплейса.
- Если подъём указан как «включён в стоимость доставки», отдельная сумма отсутствует или равна 0 — услугу подъёма в Dalli не добавлять.
- Для отдельно оплаченного подъёма использовать КГТ-доставку Dalli; Dalli может нормализовать service 30 в service 32 для региональной КГТ-доставки.
